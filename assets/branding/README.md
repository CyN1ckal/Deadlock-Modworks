# Modworks icon

`modworks.svg` is the editable source. The mark is a flat M on a dark rounded square. The corner radius is 12 percent of the side (`rx="30.72"` in a 256 view box). Pixels outside the square are transparent. The icon has no text.

| Part | Fill |
| --- | --- |
| Backing | `#141B23` |
| Rear tiles | `#659BC3` |
| Inner strokes | `#4682B4` |
| Outer strokes | `#E6EDF3` |

Two lighter rectangles sit behind the uprights, shifted up, so each outer stroke is the front of a short stack. The steel-blue inner strokes meet at one low center point.

## Raster

Tool: ImageMagick 7.1.2-27 Q16-HDRI, using its built-in SVG renderer. No package was added for the product.

From this directory, the 256px PNG and the 32, 48, 64, 128, and 256 ICO frames:

```
magick -background none -density 768 modworks.svg -filter Mitchell -resize 256x256 -depth 8 PNG32:modworks-256.png
```

`-density 768` draws the 96 DPI SVG at 8x, then Mitchell scales it down. Repeat the command with another side length for the other frames from 32 upward.

`modworks.ico` contains 16, 20, 24, 32, 48, 64, 128, and 256. Each frame is a 32-bit PNG inside a normal ICO directory. Python 3.14 and Pillow 12.2 pack those PNGs. ImageMagick 7.1.2 writes uncompressed BMP frames instead, so the committed file was packed with Pillow.

## 16, 20, and 24

The rear tiles are omitted. They blend into the stems at these sizes, and a legible M wins. The backing is still the rounded square at 12 percent radius, drawn with the command above (`-density 1536` at these small sides). Pillow then paints the M as opaque pixels so the strokes stay on the grid.

`S` is `#E6EDF3` and `B` is `#4682B4`. `.` is the backing. A space is a transparent corner pixel.

Uprights are 2px wide at 16 and 3px wide at 20 and 24. The inner strokes start 2px wide, step inward, and meet on a single row: y=8 at 16, y=11 at 20, and y=13 at 24.
